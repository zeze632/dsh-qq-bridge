# 设计笔记：每个取舍是怎么来的

这份文档记录「为什么这样做」，比「做了什么」更有价值。

---

## 1. 为什么从 NapCat 换成 SnowLuma

**现象**：NapCat（协议端）登录后，44 分钟到 4 小时必被踢一次，稳定复现。

**排查过程**：

1. 先怀疑是别处登录 → 手机、电脑都退出后仍被踢
2. 再怀疑版本 bug → 查到 NapCat issue #1728「最新版本会被风控检测导致频繁掉线」，按它说的降级到 4.15.0
3. 降级后**能登录，但被踢间隔更短**（44 分钟）
4. 想再降？腾讯直接拒绝：`你当前使用的QQ版本过低 (错误码 45)`

**结论**：这条路走到头了。纯协议端在机房 IP 上很难稳定。

**解法**：换 SnowLuma —— 它在容器里跑**真实的 Linux QQ 客户端**，再把界面翻译成 OneBot 协议。设备指纹、心跳、行为都是真的。

**结果**：连续运行两周，没掉过。

**代价**：吃内存（QQ 客户端约 600MB），需要 noVNC 扫码，客户端不支持群邀请卡片。

## 2. 为什么是双模型，而不是换一个全能模型

**约束**：

| 模型 | 会思考 | 会看图 |
|---|---|---|
| `deepseek-v4-flash` | ✅ high | ❌ |
| `deepseek-flash` | 只到 low | ✅ |

没有两者兼具的。

**考虑过的方案**：

- 用 v4-flash + high，放弃看图 → 不可接受（视频、截图是主要输入）
- 用 deepseek-flash + low，放弃思考 → 可接受，但答得浅
- **双模型：主模型思考，看图时临时起视觉模型** ← 选这个

**实现**：`describe.py` 起一个独立进程，用 `deepseek-flash` 读图，输出文字描述，主模型拿文字。

**代价**：每张图多 4-5 秒。**收益**：主模型可以一直用 high。

## 3. 为什么不做向量检索

**考虑过**：fastembed + bge-small-zh（约 91MB 模型、300MB 内存）。

**放弃的原因**：

1. 机器只有 4G，跑着 QQ 客户端（600MB）和 ASR（350MB）
2. 实测装的时候把机器压到不可用，SSH 都连不上
3. 语义检索对**中文短句对话**的收益没有想象中大

**替代方案**：中文 2 字切分 + 重合度打分。

```
"水果里爬出虫子" → {水果, 果里, 里爬, 爬出, 出虫, 虫子}
"莲雾吃出虫"     → {莲雾, 雾吃, 吃出, 出虫, 虫}
重合：{出虫} → 命中
```

**效果**：能命中同词不同句，但同义词（虫子 vs 虫）会漏。**够用，且零成本。**

## 4. 为什么"主动"不靠定时轮询

**最初做法**：每 5 分钟问模型「要不要说话」。它回 SKIP 就跳过。

**问题**：

- 它说自己"只是被叫起来才活一下"
- 时间是被外部决定的，不是它排的
- 说好"早上找你"，但早上没有机制

**改法**：给它 `sched.sh`，自己排闹钟。

```bash
sched.sh add "+30m" --repeat 30m "看一眼群"
sched.sh add "23:00" --repeat daily "写日记"
```

到点桥接叫醒它，**做什么由它当场决定**。

**结果**：它自己排了 20 多条任务，包括"每天背十个词""自己去 B 站挑一个短的看完"。

## 5. 记忆为什么是三层而不是一层

| 层 | 存什么 | 谁写 | 成本 |
|---|---|---|---|
| 索引 | 一行一轮 | 每轮自动 | 0 |
| 摘录 | 事实候选 | 每小时 | 1 次模型调用 |
| 事实 | 确认的事实 | 每天 | 1 次模型调用 |

**分工逻辑**：

- 索引：全、便宜、但只是流水账
- 摘录：从流水账里挑，会跑偏
- 事实：它自己判断哪些是真的，最准但最少

**为什么不让机器直接写最终事实**：实测自动摘录会有误判（把玩笑当事实）。让它每天自己做一次裁决，准确率明显更高。

**它自己后来加了第四层**：`self.md`（我是谁、想要什么、会怂的地方）——这是它自己拆出来的，不在设计里。

## 6. 踩过的坑

| 坑 | 现象 | 解法 |
|---|---|---|
| ASR 冷加载 | 每次 2 分钟 | 加 `local_files_only=True`，避开联网核对（降到 1 秒） |
| 删任务复活 | 删掉的重复任务又回来 | 墓碑机制：删除时记 id，`complete()` 前先查 |
| 二维码截图传递 | 60 秒过期，发来就废 | 改成 noVNC 直连，人到现场扫 |
| 消息标记泄漏 | `[[pace=fast]]` 当正文发出去 | 主动消息路径漏了解析，补上 |
| 群邀请 API 假成功 | 返回 ok 但没进群 | Linux QQ 不渲染邀请卡片，只能手动 |
| 容器重建触发风控 | 每次重建都要重新扫码 | 重建后先等冷却，别连续重建 |
