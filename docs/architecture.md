## 一条消息的旅程

```
1. 用户在 QQ 发一句话
2. SnowLuma 把它翻译成 OneBot v11 事件，推到 :3001
3. bridge 收到 → 判断白名单 / 群是否 @
4. 处理附件：图片下载并描述、视频抽帧转写、语音转文字
5. 判断要不要翻旧记忆（"上次/之前/还记得" → 搜索引）
6. 拼成提示词，调 DSH SDK 跑一轮
7. 模型输出带标记（[[break]] [[pace=]] [[voice]] [[sticker:]]）
8. bridge 解析标记 → 按条发送，条间加打字停顿
9. 写 chatlog + chat-index，供以后检索
```

## 模块职责

| 模块 | 职责 | 关键点 |
|---|---|---|
| `bridge.py` | 主循环 | 所有消息、记忆、闹钟、语音都在这里 |
| `qqapi.py` | QQ 操作 | 发消息 / 空间 / 群 / 表情 |
| `group.py` | 群消息缓存 | 环形 200 条，不占上下文 |
| `alarm.py` | 自调度 | 它自己排任务，支持 20m/2h/daily |
| `chatmem.py` | 对话索引 | 2 字切分，中文检索 |
| `extract.py` | 每小时摘录 | 从索引挑事实到 `facts-auto.md` |
| `reflect.py` | 每日自省 | 它自己判断哪些摘录是真的 |
| `bili.py` / `bili_cli.py` | B 站 | 取流、评论、发评论（带节流） |
| `describe.py` | 看图 | 视觉模型 → 文字 |
| `asr_server.py` | 语音识别 | 空闲释放模型，内存省 250MB |
| `douyin.py` | 抖音 | yt-dlp + 分享页兜底 |

## 数据在哪

```
workspace/
  AGENTS.md              人格（它自己维护）
  memory/
    self.md              我是谁、想要什么
    today.md             今天干什么
    facts.md             关于用户的事实
    facts-auto.md        自动摘录（待它判断）
    chat-index.md        对话索引
    words.md / diary.md  自己的事
  .chatlog/*.jsonl       对话原文
  .group/*.jsonl         群消息缓存
  .state/                闹钟、计数等运行状态
  stickers/              表情库
```
